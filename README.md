## 📝 Project Overview

This café restaurant website offers a modern, user-friendly interface to showcase menu items, promotional offers, delivery information, and more. It is fully responsive and optimized for all devices.

---

## 🚀 Key Features

### 🔝 Header Top Section
- Shows opening hours, contact number, and discount offers.

### 📌 Sticky Navigation Bar
- Fixed navigation bar with smooth scrolling.

### 🎯 Hero Section
- High-converting section with delivery promotion and call-to-action button.

### 🧾 About Us
- Clean section describing the café's locally crafted food service.

### 🍽️ Services Area
- Built using **Bootstrap 5 Grid System**.
- Interactive service cards for: Breakfast, Lunch, Dinner, and Custom Orders.
- Cards feature hover effects with background color change.

### 🥘 Featured Items
- Popular dishes displayed with:
  - Name, price, delivery time
  - "Order Now" button for each item

### 🚚 Quick Delivery Banner
- Emphasizes fast delivery services with strong visuals.

### 📧 Newsletter Subscription
- Clean input field for customers to subscribe and stay updated.

### 🔻 Footer
- Includes navigation links, copyright,
- Social media integration for extended engagement.
